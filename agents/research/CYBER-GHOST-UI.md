# CYBER-GHOST-UI – references

**The idea:** a mood for the editor and deck surfaces, somewhere between a ghost in the machine, a ritual and an instrument. The light is phosphor, signal glows on black, the linework is thin, the data is dense, and machines and tissue mix. The owner (2026-11-16): "the 3d scene of course stays our normal 3d scene. it is just the ui layer that changes."

## The owner's notes on it

- "every little node is a mini screen on a circuit board … real wires going there … some modules are organic tissue"
- "we will need to use bitmaps. because this stuff is insane to render as vector": nine-slice plates from one atlas, each node's live content in its own small texture, cables as textured strips, one shader pass per effect (sparkle stamps, an edge pass, scanlines).
