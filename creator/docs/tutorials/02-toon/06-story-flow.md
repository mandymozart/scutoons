## Steps

1. On the toon page the round flow button opens the toon’s “Flow”: seasons, chapters, map and jumps. In the chapter editor the same button shows this chapter’s story flow.
2. It is read-only: a box opens its chapter, so you fix things where they are.
3. The chips show the trouble: “may get stuck” (every choice has a condition – give one none, like “Go on”), “unreachable”, “endless loop” or “never true”.
4. “Unused” lists variables set but never read, read but never set, and points nothing jumps to.
5. “Flow” in the menu shows every toon and the jumps between them.
