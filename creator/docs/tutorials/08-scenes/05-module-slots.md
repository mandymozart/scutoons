## Steps

1. The camera’s slot is in the “MODULES” section of the “DOP” panel; a member’s slot in “MODULES” in its inspector.
2. An empty slot is dashed: drag a module from the library onto it. It lights up while you carry one over.
3. Start with dolly on the camera (it pushes in and back on the clock) or bob on an item (it floats).
4. The filled slot shows its module; “×” takes it off.

## Note

A module needs a build before it fits a slot: “module:… has no descriptor yet – build it first”.
