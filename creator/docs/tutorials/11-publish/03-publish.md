## Steps

1. “Save” (or Ctrl+S) stores a draft: only creators see it. The note “Save” asks for says what changed.
2. The phone icon in the top bar opens the “Reader” in the dock – choose “Phone” or “Desktop”. It shows your saved drafts as readers will see them.
3. “Problems” in the bottom bar lists errors and warnings; “Go to the place” jumps there. A warning that is fine can be accepted, an error can’t.
4. “Publish” lists every file with a draft readers don’t see yet. Untick what should wait, then press “Publish n”.
5. Does your toon have reviewers? Then the button is “Submit for review”: add a “Note for the reviewers” and press “Submit” – they publish it or send it back.
6. “Publish” on the start page does it for everything at once: every toon and the world (map, characters, settings).

## Note

Published means readers see it right away. Every earlier version stays in “History” → “Versions”.
