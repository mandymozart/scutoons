## Steps

1. In the chapter tree choose “Audio”. Under “Music” add tracks with “+ Track” (an “ID” and a “File”), and set the “Default track” and the “Crossfade (ms)”.
2. Under “Sample library” add each sound with “+ Sample”: an “ID” and a “File”.
3. Select a slice and open its “Audio” tab: the “Music” faders set each track’s volume from this slice on. “×” goes back to the earlier level.
4. Under “Samples” add “+ on scroll” (it plays when the slice comes into view) or “+ on click (area)”, and choose its “Sound”.
5. Set “Volume”, “Delay (ms)”, “Loop” and the rest per sample. Draw a click area with the “Sample area” tool on the slice.

## Note

Music and samples are shared by every language. File paths are relative to the toon’s media folder.
