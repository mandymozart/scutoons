## Steps

1. On the toon page, under “Languages”, “+ Add” adds a translation. Save the draft before the editors offer the new language.
2. Switch the text language with the globe select in the top bar: the source is marked ★, and the button turns dark while you see a translation.
3. Type the translation into each text field; the original shows under it. On a phone, “Copy the original” fills it in to start from.
4. For a script or Kanon text the empty language offers “Start empty” or “Copy the … script”.
5. Check the “Problems”: a missing translation and a text much longer than the original (over 130 %) are warnings.

## Note

The source language is changed on the script page (“Make … the source”), after the script is saved.
