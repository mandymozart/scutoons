## Steps

1. Switch to “Module” and pick a module in the “Library”. A rig without one offers “New module” for its character.
2. “Open in editor” opens the module’s code in your code editor (VS Code, or the command in DECK_CODE_EDITOR).
3. Press “Build”. When it works the parameters read “heard on the stage”; if not, the “Problems” panel lists them and a click opens the code there.
4. Turn its parameters and listen. The working copy saves itself as a draft whenever its sources change.
5. Back in “Build”, add it to a rig as a track: “Add” → module:<name>.

## Note

A factory module is read-only: it saves as a module of your own, my_<id>.
