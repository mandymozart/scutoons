## Facts

- Start it: cargo run -p deck-editor in the deck folder; a deck with the full image has it built in.

## Steps

1. Start the deck editor: it opens in “Build” with a rig on the stage.
2. Sign it in once: point at the account icon (top right) for its code and approve it on scutoons.com under Account → “Pair a deck”. The editor then reads and saves drafts; publishing stays in the creator.
3. In the “Inspector” click the rig’s name at the top: the list shows your toon’s rigs – pick one.
4. The editor starts in the wiring. The play button beside the BPM (or W) plays the rig as a deck plays it.
5. Drag a knob to turn it, anywhere else to orbit. Shift + drag pans, the wheel zooms, F frames everything.
6. There is no save button: the rig saves itself as a draft (Ctrl+S saves at once).

## Note

The approval code changes every 10 minutes, and only creator accounts can approve it.
